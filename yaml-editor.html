⚡ OpenCode Infinity

配置編輯器 - 視覺化介面

💻 常用命令參考

python3 opencode-infinity.py <session_id> <config_name>
基本用法：使用指定配置運行
python3 opencode-infinity.py ses_open opencode-example
OpenCode 範例 - 通用任務自動執行
python3 opencode-infinity.py ses_codex codex-example
Codex 範例 - 7x24 持續運行（推薦）
💡 提示
• Session ID 可以自訂（例如：ses_open, ses_codex）
• 配置名稱支持三種格式：配置名、文件名、路徑
• 使用 Ctrl+C 停止執行並查看統計信息
• 運行中可隨時修改 YAML 配置，每輪自動熱更新
• 所有配置文件位於 tasks_yaml/ 目錄
